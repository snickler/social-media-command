## Accessing Documentation

The documentation can be accessed in multiple ways:

1. **Through the Application**: Click the documentation (book) icon in the application toolbar
2. **Direct File Access**: Browse the files in this docs folder
3. **Web Interface**: Available through the integrated Vite frontend

## Contributing to Documentation

When adding or updating documentation:

1. Place files in the appropriate category folder
2. Update the relevant README.md files
3. Follow the existing markdown formatting conventions
4. Test the documentation display in the application
