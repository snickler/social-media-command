# Social Media Management Hub - User Guide

## Overview

The Social Media Management Hub is a unified platform for creating and managing social media content across multiple platforms. This guide will help you understand all the features and capabilities of the application.

## Getting Started

### Basic Navigation

- **Standard View**: Default layout with separate sections for platform selection and post creation
- **Compact View**: Split-screen interface with feeds and post composer side by side
- **Documentation**: Access the help and documentation by clicking the book icon in the top toolbar

### Creating a Post

1. **Select Target Platforms**
   - Click on the platform icons to select where you want to post
   - Each selected platform will appear highlighted
   - Some platforms have specific content limitations (e.g., character limits)

2. **Select Accounts**
   - For each platform, you can choose which account(s) to post from
   - Click the "Manage Accounts" button to add or edit accounts
   - You can select multiple accounts per platform

3. **Compose Your Content**
   - Type your message in the text area
   - The character counter will show how many characters remain
   - Platform-specific previews show how your post will appear on each network

4. **Add Media (Optional)**
   - Click the image icon to upload images or videos
   - Drag and drop files or use the file browser
   - Preview uploaded media before posting

5. **Use Promo Mode (Optional)**
   - Toggle "Promo Mode" to automatically add hashtags to your post
   - Edit the hashtag list to customize which tags are included
   - Hashtags are added to the end of your post on platforms that support them

6. **Post Your Content**
   - Click the "Post" button to publish to all selected platforms
   - A success message will appear when posting is complete

## Thread Features

### Thread Mode vs. Threads-Only Mode

- **Thread Mode**: Create a thread but can still post single posts
- **Threads-Only Mode**: Create threads exclusively (only thread-supporting platforms available)

### Creating a Thread

1. Enable Thread Mode using the toggle in the post editor
2. Write your first post in the main editor
3. Click "Add Thread Post" to create additional posts in the thread
4. Each thread post can have its own media attachments
5. Rearrange thread posts by dragging them
6. Click "Post Thread" to publish the entire thread

## Account Management

### Adding a New Account

1. Click the "Manage Accounts" button in the toolbar
2. Select the platform you want to add an account for
3. Click "Add Account"
4. Fill in the account details (username, display name)
5. Optionally set as default account
6. Click "Save"

### Managing Multiple Accounts

- Select which accounts to use when posting
- Set default accounts for each platform
- Edit or remove accounts as needed

## Tips and Best Practices

1. **Platform-Specific Content**
   - Different platforms have different character limits and media support
   - The app will warn you if content exceeds platform limitations

2. **Using Hashtags Effectively**
   - Use relevant hashtags to increase post visibility
   - Don't overuse hashtags as it can appear spammy
   - Edit the default hashtag list to match your content themes

3. **Media Best Practices**
   - Use high-quality images when possible
   - Be aware that image cropping varies by platform
   - Video length limitations vary by platform

4. **Thread Strategies**
   - Use threads for longer content that exceeds character limits
   - Break complex topics into digestible thread posts
   - Consider adding media to specific thread posts for emphasis

5. **Multi-Account Management**
   - Set clear default accounts to avoid accidental posting
   - Regularly verify selected accounts before posting
   - Use account selection to target different audiences

## Troubleshooting

### Common Issues

- **Platform Selection**: Make sure at least one platform is selected before posting
- **Account Selection**: Each platform must have at least one account selected
- **Thread Mode**: In Threads-Only mode, you must add at least one thread post
- **Media Upload**: If media fails to upload, check file size and format
